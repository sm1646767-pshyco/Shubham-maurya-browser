⚠️ First-Time Installation

App unsigned hai, isliye macOS/Windows pehli baar warning dega. Ye normal hai — app safe hai.

🍎 macOS

Agar "Malware Blocked" ya "Unidentified Developer" popup aaye:

Terminal me ek command: sudo xattr -cr /Applications/Universal\ Browser.app

Ya phir: System Settings → Privacy & Security → "Open Anyway"

🪟 Windows

Agar "Windows protected your PC" aaye:

  1. "More info" click karo
  2. "Run anyway" click karo
  3. Install ho jayega
