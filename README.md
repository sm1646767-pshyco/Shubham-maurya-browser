## 🚀 Build From Source

```bash
# Clone
git clone https://github.com/sm1646767-pshyco/Shubham-maurya-browser.git
cd Shubham-maurya-browser

# Install
npm install

# Run
npm start

# Build
npm run build:mac    # Mac
npm run build:win    # Windows
