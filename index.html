Mobile Pe Install Karo

Ye browser abhi Mac aur Windows pe available hai.
Mobile pe PWA install karke use karo — home screen pe icon ban jayega.

🤖
Android: Chrome me kholo → Menu (⋮) → "Add to Home screen"
🍎
iOS: Safari me kholo → Share (□↑) → "Add to Home Screen"

Home screen pe "UB" icon ban jayega — tap karo aur browser khulega!
